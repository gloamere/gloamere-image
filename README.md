# gloamere-image 0.7.0 开发候选

Windows 优先的本地看图与轻编辑工具，Rust + egui/eframe + wgpu。当前开发版采用按需 AI 检测，并实现可信更新、稳定入口及持久恢复路径。云端测试不代表 Windows 原生安装或模型准确率验收通过。

## 按需 AI 检测

- 默认不检测。点击“更多（…）→ AI 检测当前图片”，仅检测当前图片；打开、切图、滚动列表和刷新目录不会启动 AI 检测或文件夹来源扫描
- 已安装组件在首次主动检测时异步校验并接续本次请求，普通看图不加载模型做自检；缺少组件时显示现有组件指引，不自动下载
- 无需像素检测组件，也可在详情中主动“读取来源信息”，随后使用独立人工标记；该操作不执行像素模型
- 组件安装状态、当前图片执行状态和模型发布资格分别显示。来源检查完成不等于像素检测完成
- 已安装组件执行成功显示“实验检测已完成”；正向信号最多是“疑似 AI · 实验”；未见强信号同时说明“不能排除 AI”
- 固定可信组件哈希和正式质量门槛独立，下载签名或缓存均不能批准模型
- 人工记录保留，模型结果与人工决定并存；角标是 UI 叠加，不写入原图、复制或导出像素
- 单 worker、明确取消/超时、同名换图与模型版本失配失效；不支持输入不会变成“非 AI”
- 模型仍有真实漏检：所给已知 AI PNG 的当前候选得分仍为 −4.0221，未调整阈值或针对样图硬编码

当前交互见[手动检测设计](docs/manual-ai-detection.md)。[v0.7 AI 实现与验证](docs/v07/ai.md)保留先前实现的输入边界、缓存兼容与历史证据，其中自动筛查交互已由当前手动策略替代；尚未通过独立大规模模型质量门槛。

## 可信更新与安装恢复

“自动更新应用”与“自动更新已安装模型组件”独立、默认关闭。应用更新只在正常退出并完成安全条件后安装，不关闭其他窗口、不重启系统。更新偏好使用独立文件，v0.6 原设置格式保持可回退。

首次 v0.7 需要一个引导 Setup EXE，安装稳定入口和 runtime 布局。之后走同类 EXE，保留稳定 launcher，持久快照直到真实健康启动；签名/哈希、路径、所有权、进程和恢复条件失败时停止。

当前没有已配置的生产可信根或 IP HTTPS 仓库，因此该源码候选不联网自动更新。用户选择的无 Authenticode 方案仍要求 TUF 发布签名与有效 HTTPS，不能绕过 Windows 保护。测试仓库不代表生产服务已上线。

[更新实现与限制](docs/v07/updater.md)与[实施附录](docs/v07/implementation-addendum.md)说明代码边界；主程序仍仅使用最终原生验收的 Setup EXE 分发，源码 ZIP 不是安装包。源码提交与推送不代表安装包已通过最终原生验收或已正式发布。

## 查看与阅读

- JPEG、PNG、静态 GIF/WebP；格式以内容探测为准，APNG 暂不支持
- GIF/WebP 动画按需、有界解码；播放/暂停、下一帧、从头播放和帧/时间状态
- Ctrl+V 显式从剪贴板打开图像或单个本地图片文件；Ctrl+C 复制完整图像，动画复制当前静态帧
- 左右键切图；默认按文件名自然排序（image2 在 image10 前）；每次启动默认隐藏列表，左上角分栏按钮一键显示/隐藏；列表支持文件名搜索，“筛选与排序”中可按修改时间/文件大小排序、按 JPEG/PNG/GIF/WebP 扩展名及 AI 状态筛选
- F 适应窗口，1 实际像素，普通模式滚轮缩放，拖动平移
- 主画布与 A/B 的 B 画布支持右键菜单，可贴图、复制、导出、适应窗口、查看 1:1，以及进入编辑、文件操作和按需 AI 检测；空画布右键提供打开与粘贴。按住右键拖动仍可平移，裁剪模式保留此操作
- “更多 → 查看 → 长图适应宽度”显式进入阅读模式：滚轮纵滚、Ctrl+滚轮缩放，PageUp/PageDown 翻屏，Ctrl+Home/End 到顶/底；Home/End 仍跳目录首尾
- “更多 → 查看 → 像素与透明度检查”提供坐标、当前 sRGB 8 位 RGBA/HEX、单击复制颜色，以及平滑/锐利显示切换；Alpha 灰度查看只改变画面，动画和双图对比期间暂用正常画面
- “更多 → 查看 → 双图 A/B 对比”固定当前静态图为 A，再打开另一张作为 B；同尺寸图片可同步缩放/平移，编辑、复制和导出仍针对 B，不自动对齐或计算差异
- 主窗口标题栏左侧显示当前文件名，双击可重命名原文件；只修改文件主名、保留扩展名，不覆盖同名文件。有未导出修改时先处理当前修改，剪贴板图片和提取帧没有此操作
- 标题栏空白区域可拖动窗口，双击切换最大化/还原；右侧提供小图钉与最小化、最大化/还原、关闭按钮。关闭继续检查未导出修改
- 标题栏右侧的正立小图钉可直接创建独立贴图；也可通过画布右键“贴图置顶”或“更多 → 查看 → 贴图置顶（独立参考窗）”操作。独立贴图无边框、无工具栏，最多同时 3 张；冻结创建时已显示的图片或动画当前帧，主窗口可继续切图、编辑。拖动图片移动贴图，悬停时滚轮按图片比例连续缩放，无需先点击激活；图片和菜单外的透明区域不阻挡点击。右键可恢复初始大小或关闭，Esc 可单独关闭
- “更多 → 查看 → 当前窗口置顶”切换主查看窗口的层级，保留当前大小和位置；与创建独立贴图分别操作
- F11 全屏；空闲约 1.8 秒隐藏底栏，鼠标移动/底部边缘/键盘活动唤回；弹窗、编辑或键盘焦点期间不自动隐藏
- Ctrl+O 打开、R/Shift+R 右/左转、Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做、F5 重新载入当前文件、Ctrl+Shift+S 导出新副本、F10 更多
- “更多 → 文件”提供“在文件夹中显示”和“复制文件路径”；剪贴板图片和提取帧没有原文件路径，不提供这些文件操作
- Esc 每次关闭一层：菜单/提示、确认/对话框、裁剪工具、编辑/信息面板，最后退出全屏

底栏保持单行图标，按逻辑宽度显示 11/8/7 个常用操作；AI 检测等低频项进入“更多”，触区不少于 32 逻辑点。小于 800 点时编辑为底部抽屉；关闭与导出保留可达位置。实际 100/125/150/200% Windows DPI、鼠标/触控板/IME 尚需原生验收。

文本/数值框有焦点时，Ctrl+C/V 保持文本语义。剪贴板只在明确操作时访问，不后台监听、不保存历史、不抓取 URL。Windows 原生 PNG/DIBV5/DIB 和应用互通仍需按矩阵验证；macOS 的剪贴板目前明确返回未支持，不声称完成跨平台兼容。

新增工具的入口、交互和限制见[查看工具说明](docs/viewer-tools.md)。排序/筛选、像素检查、对比、窗口置顶与独立贴图均为当前会话状态，不写入设置文件。主窗口退出会关闭全部贴图，不后台常驻。

## 编辑、保护与导出

图像编辑不写回原文件，导出创建新副本；只有明确确认重命名时才修改原文件名称，不改图像内容。支持旋转、水平翻转、裁剪、保持比例缩放、撤销和重做。新编辑会清空重做分支；撤销与重做合计最多保留 3 项、256 MiB，包含历史像素及其已准备的显示数据。裁剪/缩放各显示当前工具字段，信息与来源独立查看。

有未导出修改时，切图、重新打开、粘贴、恢复原图和正常关闭会询问“导出副本后继续 / 放弃改动并继续 / 取消”。只有对应导出成功才继续原操作；导出失败或取消保留当前编辑。重复导航只保留第一个待确认意图。重命名要求先导出副本或放弃当前修改，再重新发起；不会在仍有未导出修改时直接改名。

动画编辑/导出必须明确“提取当前帧为静态副本”；之后仅输出 PNG/JPEG，不编码动画。剪贴板与提取帧使用无原文件路径的临时会话，不伪造文件哈希、EXIF 或有效来源签名。

F5 会清除静态浏览缓存并重新读取当前文件，未导出修改仍先确认。切换导出 PNG/JPEG 时保留自选目录和文件主名，仅更新扩展名，并作废上一格式的 JPEG 预览。

导出使用同目录独占临时文件、编码后验证和无覆盖发布。原图、已有同名文件不被覆盖。取消与发布在同一原子门禁排序：取消先赢则不发布，发布先赢则报告真实完成结果。正常退出回收文件拥有线程，不用强制退出掩盖清理。同步 codec、OS 文件系统调用和 GPU 驱动阻塞没有硬中断保证，断电/强杀另列限制。

## 资源与颜色边界

- 静态输入：64 MiB、1600 万像素、单边 32768
- 动画输入：64 MiB、400 万画布像素、每次遍历最多 2000 帧
- 动画应用合成/预读缓冲最多 128 MiB，同时计入全局估算准入；只保留当前与一个待显示帧，不收集全部帧
- 超过动画画布上限直接安全拒绝，不额外解码超限首帧；坏帧或遍历超限暂停并保留最后正确帧，不当作完整播放结束
- 小于 20 ms 的动画延时统一到 20 ms，并显示规范化说明；失焦、最小化或打开弹窗时暂停，不积压补播
- 同目录最多扫描 10000 条目、列出 8000 张；按需缩略图最多 48 张，受固定浏览预算覆盖
- 切图保留当前画面，新图完成后台解码/显示准备后再替换；同网格使用局部更新复用 GPU 纹理，交接数据保留逻辑预算
- 最近静态原图缓存最多 2 张、192 MiB（包括 RGBA 和 CPU 显示数据），命中前核验文件身份；编辑/导出和预算压力会回收缓存，不缓存动画
- 缩略图走独立首帧预览路径，JPEG 使用 IDCT 缩小解码；PNG 逐行检查取消，预览不计算来源哈希或创建动画播放状态
- Alpha 派生在后台执行，可取消且计入全局预算；切图/编辑后不沿用旧 Alpha，准备失败保留正常图。A/B 固定图及其显示数据同样保留预算所有权，退出对比后释放
- 独立贴图共享创建时已准备的显示像素与纹理所有权，后续主窗口更新不覆盖已冻结内容。每张贴图从创建到关闭使用固定绘制画布，按所用显示器工作区的实际物理面积预留显示缓冲预算，16 MiB 仅为每窗下限；缩放图片不逐帧改变原生窗口尺寸，也不缩减此预留。关闭后经渲染交接释放，最多同时保留 3 张

768 MiB 全局预算是保守应用准入估算，不是进程私有内存、GPU 驱动或恶意 codec 的硬沙箱。请勿把逻辑预算当作已达性能承诺。

保留 EXIF 八方向归一、ICC 转 sRGB、透明像素和预乘 alpha 缩放。16 位输入明确转为 8 位副本；ICC 失败可查看，但拒绝输出声称已校准的副本。画布背景只影响查看，不污染导出或复制。JPEG 底色与画布分开选择。

## 安装与更新兼容

沿用相同 AppId、ProgID、Programs/LightImageTool 安装目录和 LocalAppData/LightImageTool 设置目录。v0.7 引导将真正 UI 与 worker 放入 runtime，快捷方式和 --open 保留稳定根入口。精确登记和默认关联保护继续有效，不写 UserChoice。

settings.json 仍为 schema 1；未知/损坏/未来版本文件保留且拒绝覆盖。图片和人工标记不在应用安装目录，不参与更新替换。正式上线仍需要同一候选的 Windows EXE/Setup、升级、断电恢复和系统保护验收。

## 来源与范围

来源检查独立、按需、离线执行；普通查看和编辑不抢首图启动核验。官方 C2PA worker 不启用 HTTP 传输或远程获取；Windows JobObject 约束只覆盖来源 worker，不能当作主图 decoder 已被沙箱化。

凭据存在、签名、资产绑定、信任及离线缺失分别陈述。签名有效不等于画面真实，无凭据不代表非 AI；编辑/复制/提取的像素不继承原有效签名。

本版不包含 RAW/HEIC/AVIF/SVG/压缩包、OCR、云端 AI、批量编辑、自动图像对齐/差异计算、动画编码、后台系统服务或 macOS 正式分发。
