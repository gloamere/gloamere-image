# gloamere-image：改名、图标与 EXE 更新设计

2026-10-09，先设计后实施。用户要求：软件改名为 `gloamere-image`；补齐图标；打包和更新统一使用 EXE 安装包。此前轻图 v0.4 r2 候选被本轮替代，不作为安装建议。

## 一致的产品身份

- 用户可见品牌精确为 `gloamere-image`：标题栏、文件对话框、错误窗口、安装/卸载向导、开始菜单、候选应用、右键菜单、版本资源、README 与当前发布指引。
- 主程序改为 `gloamere-image.exe`；离线来源后台改为 `gloamere-image-worker.exe`。主程序只寻找新名称 worker，避免误启动旧版本后台。
- 产品版本仍为 0.4.0，作为此前未安装候选的后续修订。
- 保留 AppId/OwnerId、原卸载键、原安装目录、`LightImageTool.Image` ProgID、历史设置目录/schema、安装归属标记和恢复目录。它们是兼容标识，不是新增软件或第二套安装。
- 内部 Cargo package/library 身份保持兼容；显式声明新二进制名称。历史测试/版本文档不伪改为已验证新品牌。

## 图标体系

- 原创 SVG 品牌图形，暮色图像/画框构图，深青和暖琥珀；不复制其他品牌，不包含用户示例图片。
- 从同一 SVG 常规渲染多尺寸 PNG 和 ICO，资源小、可重新生成，不引入图标字体。
- 分别接入 Windows EXE 资源和 egui viewport 图标，覆盖可执行文件、标题栏、任务栏。Windows 进程在显示 UI 前设置与快捷方式相同的稳定 AppUserModelID，不扫描或改写用户固定项。安装/卸载、快捷方式、文件候选图标引用相同品牌资源。
- 保持现有底部 11 个自绘矢量操作图标；更多菜单、编辑、列表和导出的主要动作补充同风格图标，保留中文文字、可访问名称和快捷键。图标不替代必要的安全文字。
- 新视觉不侵占主体画布，不新增常驻大侧栏；800×550、高 DPI、焦点与快捷键回归继续执行。

## 升级与发布

- 终端用户仅获得 Setup.exe。首装与升级均运行同类安装器，保留原位置和偏好；没有自动更新服务、联网检查或新域名。
- 内部构建暂存 payload、源码归档和开发 QA 资料仍允许，但不再把 portable ZIP 当作终端用户安装/更新途径。
- 旧 EXE/worker/快捷方式/产品注册迁移必须先核验归属、路径和固定目标，再纳入失败恢复；文件缺失或改变、未知注册值不猜测修复或删除。
- 注册表继续严格 REG_SZ+文本匹配和同视图查询；共享父键保留。默认应用设置仍可选、默认不勾选，只由用户选择关联，不写 UserChoice。
- 详细安装迁移边界见 `branding-installer-migration.md`；图标与资源构建见 `branding-icons.md`。

## 验收分层

1. 云端：SVG/PNG/ICO尺寸/alpha/一致性，资源脚本静态/单元检查，Rust fmt、Windows目标check/clippy，Linux无头UI及核心回归，真实egui离屏预览。
2. Windows：原生资源编译链接，EXE版本信息/文件图标、标题栏/任务栏图标、安装器/卸载器/快捷方式/候选应用图标；新品牌界面与真实输入。
3. 安装生命周期：v0.3原位升级、品牌版本重装、故障恢复、旧文件占用与篡改拒绝、额外用户文件/偏好保留、唯一卸载项、旧图标缓存刷新与默认选择不变。

云端检查不代替 Windows 原生构建/安装测试。旧产品已验证结果不自动转为新品牌通过。
