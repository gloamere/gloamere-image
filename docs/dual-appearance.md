# 双主题与统一工具岛

资料核验日期：2026-10-21。本文记录当前开发候选的设计、实现边界与验证进展；运行验证由主代理统一核验，已完成与待复核项分别列于文末。

## 外观与画布

采用 C 方案的薄工具岛和安静留白，深色使用 B 方案的炭灰色系，浅色使用 C 方案的浅色系。两套主题共用布局、字号、图标和命中区，通过中性表面、清楚的层级与克制的强调色呈现状态。

入口为“更多（…）→ 外观”，提供“跟随系统”“浅色”“深色”，默认跟随系统，用户选择会保存到偏好设置。主题同时覆盖标题栏、列表、工具岛、菜单、弹窗和工具提示。

新安装的画布背景默认“随外观”，自动采用当前主题的中性灰。已有配置保留用户明确选择的深色、浅色或棋盘背景；缺少外观字段的旧配置按“跟随系统”读取。用户也可单独选择画布背景。

## 几何与交互

以下尺寸均为逻辑点，是本项目的具体约定：

| 元素 | 约定 |
| --- | --- |
| 底部预留区 | 高 56；使用画布背景，与主画布接续 |
| 工具岛 | 高 40；按钮左右各留 8；按剩余画布区域居中 |
| 工具按钮 | 32 × 32 命中区；窄窗口按既有断点收起低频命令到更多菜单 |
| 标题栏按钮 | 28 × 28 命中区，保留窗口控制与拖拽区域 |
| 命令图标 | 16 × 16 矢量画布，约 1.5 线宽；图钉正立、左右对称 |
| 状态 | 常态、悬浮、按下、选中、禁用和键盘焦点分别表达；一次性动作不保留开关选中态 |

列表和检查面板先占据各自区域，再计算工具岛与底部信息的位置。深浅主题使用相同布局；工具岛占用独立底部空间，图片保持原比例，不额外绘制白色图片边框。独立贴图继续沿用只展示图片的无边框窗口。

切换外观只更新界面样式和必要的重绘，不重新解码或上传图片纹理，不改变图片像素、缩放、平移、编辑状态及列表展开偏好。图片处理、缓存和既有多窗口路径继续沿用原架构。

AI 检测仍仅在用户从更多菜单等既有手动入口明确发起时执行；每次启动仍默认隐藏图片列表。独立贴图的右键菜单、细粒度缩放和 Esc 关闭行为继续保留；标题栏双击文件名重命名及窗口控制的既有安全边界继续生效。

## 工程依据

界面语义色集中在 `src/app_theme.rs`，由同一组颜色角色提供深浅两套值，供窗口、列表、按钮、菜单与提示共用。沿用当前 Rust 2024、egui 0.36.2 和现有模块边界，本次不升级依赖。

本轮组件调整的范围如下：

| 范围 | 实现边界 |
| --- | --- |
| 自绘外框与命令控件 | 标题栏、窗口控制图形、主工具按钮、项目命令矢量图标、列表行与工具岛统一几何及主题状态；窗口控制仍发送既有平台窗口命令 |
| egui 标准组件 | 文本框、下拉框、复选框、数值输入、滑块、折叠分组和确认/取消等文字按钮继续使用 egui 组件，统一应用深浅样式并保留原有输入及焦点语义 |
| 品牌素材 | logo 与应用图标继续使用现有品牌资产；命令图标的矢量重绘不替换这些图片素材 |
| 系统原生控件 | 打开/保存文件选择器及启动或运行失败时的 `rfd` 系统消息框继续由平台提供，不纳入项目的自绘控件替换范围 |
| 独立贴图 | 保留原生独立窗口和既有缩放、窗口区域处理；图片与右键菜单沿用项目绘制路径，主题切换不为贴图新增外框 |

设计依据采用核验日期当期可查的官方指导。“2026-10-21”表示资料核验时间，不另行定义所谓“2026 版”设计体系：

- [Microsoft：Color in Windows](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/color)，页面更新日期为 2026-10-13。参考其中的深浅主题、中性色层级、系统偏好和克制使用强调色原则。
- [Fluent 2：Iconography](https://fluent2.microsoft.design/iconography/)。参考图标语义清楚、纯色绘制以及尺寸适应操作场景的原则；具体矢量几何由项目实现。
- [Fluent 2：Button](https://fluent2.microsoft.design/components/web/react/core/button/usage/)。参考低强调次要操作、开关状态、可访问名称和对比度指导，保留鼠标与键盘操作能力。
- [Rust Edition Guide：Rust 2024](https://doc.rust-lang.org/edition-guide/rust-2024/index.html)。沿用仓库已有 edition，按现有 Rust 代码组织与风格实施。
- [egui 0.36.2：Options](https://docs.rs/egui/0.36.2/egui/struct.Options.html)。按当前版本的 `theme_preference`、深浅样式和 `sync_window_theme` 支持管理主题，不引入新的主题框架。

## 验证入口

运行验证由主代理统一核验。截至本次记录，已完成的结果为：

| 检查 | 结果 |
| --- | --- |
| 完整 UI 回归 | 209 passed / 3 ignored；3 项 AI 渲染资料用例因需要额外输入而忽略，不计入通过数 |
| 设置回归 | 9 passed |
| 构建 | 通过 |
| Clippy | `-D warnings` 通过 |
| 主窗口 GPU smoke | 深浅主窗口、图片列表、更多菜单、重命名与窄窗口高 DPI 等场景通过运行检查与截图复核 |
| 独立贴图 GPU smoke | 放大、缩小过程及最终截图通过；原生窗口无边框、仅图片内容，双向动画完成 |

更多菜单截图曾出现重复的键盘焦点提示，遮挡已有文字行；文字菜单按钮已改为仅悬浮提示，图标按钮保留焦点提示。修正后的 GPU 截图已确认文字行完整可见。底栏图片序号按当前实际显示的图片计算，同目录切换和跨目录切换等待期间不会提前显示目标图片的序号。

独立贴图双向缩放截图曾因调试构建同步保存 3840 × 2100 PNG 超时。使用本地临时 Cargo 配置优化根包、image 与 PNG 编码依赖后，在相同 DPI、图片及原有时限内完成双向和最终截图；没有调整生产缩放逻辑或放宽时限，也没有修改仓库构建配置。以上结果不代表发布或真实鼠标、键盘及多窗口交互验收已经完成。

现有 `--smoke <输出目录> <图片路径> <缩放>` 测试模式支持以下外观参数：

| 参数 | 用途 |
| --- | --- |
| `--appearance light` | 固定浅色界面 |
| `--appearance dark` | 固定深色界面 |
| `--appearance system` | 跟随当前系统主题 |

可与 `--show-list`、`--show-more` 等既有 smoke 选项组合检查对应界面。普通使用通过外观菜单切换；静态截图与 smoke 结果分别记录，不能据此替代真实鼠标、键盘及多窗口交互验收。
