# 轻图 v0.4：以画布为中心

设计先于实现，2026-10-08。基线：405b10ae11519d57e7302c9f41df79d8a5ae3f5e。

## 目标与边界

参考用户提供的 GuoheView 截图，借鉴白色单行工具栏、细线图标、大面积浅棋盘、右上角图片索引；不复制品牌、图标文件或示例图片。原生系统标题栏显示“轻图 · 文件名”。默认隐藏列表和检查面板。保留既有 JPEG/PNG、本地来源核验、编辑、撤销和安全导出，且不改缓存/代次/内存预算。

## 场景和状态

1. **第一次启动**：白色窗口框架，浅灰细棋盘充满画布。中间简短拖入提示，底部文件夹图标可打开；双击空画布亦可打开。“更多”及 F10 是次级功能入口。
2. **日常看图**：图片居中，默认适应但不放大小图。右上角 `1 / 19` 胶囊；底部左侧尺寸/文件大小，中央一排打开、上一张、下一张、缩小、放大、适应、1:1、右转、撤销、导出、更多图标，右侧缩放比例。每个图标有中文 tooltip、快捷键和可访问名称，键盘 Tab/Enter 仍可触发。
3. **连续浏览**：保留方向键、PageUp/Down、Home/End；列表在更多菜单开启，仍可定位当前、刷新和缩略图懒加载。列表偏好持久化，旧用户已保存的明确偏好保留。
4. **编辑**：右转和撤销留在主栏；左转、裁剪/缩放、信息/来源、全屏、路径打开和背景选择放入更多菜单。打开编辑时可见面板与关闭入口；裁剪确认继续固定可见。编辑后用右上角“已编辑”提示，来源说明保留“不代表当前像素”。
5. **背景和透明**：浅棋盘为新用户默认。保留原有四种选择：浅棋盘、深棋盘、浅色、深色。只绘制显示背景，不改 alpha、像素、JPEG 底色或导出文件。浅棋盘覆盖整个画布而非只有图片边界。
6. **耗时或异常**：加载/编辑/导出进行时画布底部显示紧凑状态和取消，错误继续原有对话框。平时底栏不增加第二行。完整状态与设置写入警告在更多菜单可查看。
7. **菜单/焦点**：菜单选择后关闭，点外部或 Esc 关闭；这一次 Esc 不顺便退出编辑/全屏。菜单和文本框开启时不触发看图快捷键。关闭面板不改变图片或启动导出。
8. **安装完成**：可选且默认未勾选“打开 Windows 默认应用设置”；点击后由用户在 Windows 自己选择 JPEG/PNG 关联。不写 UserChoice、不替换扩展名默认值、不使用关联绕过工具。兼容策略与恢复/卸载细节见 default-apps-v0.4.md。

## 尺寸与视觉

- 白色工具栏高 52 个逻辑点，1 像素细分割线；常规图标为 18–20 点、点击目标 34 点、间距 4 点。
- 常规 800×550 及以上：尺寸和大小在左，操作组居中，比例在右，始终单行，不向右溢出。
- 缩放导致更窄的逻辑宽度时：先收起旁侧元信息（完整信息仍可在信息面板/tooltip 查看），再压缩图标间隔，保留全部 11 个入口；不把工具栏挤成多行。
- 线条深灰，禁用态浅灰，悬停浅灰底，焦点可见。自绘矢量图标，无新图标库、字体包或位图资源。
- 棋盘格 16 逻辑点，灰度 249/235，随画布而不是图片移动；一张合并网格绘制，避开数千独立 egui widget。
- 编辑/信息面板使用浅色外观，不删除原有安全提示。系统标题栏继续原生，保留 Windows 拖拽、最大化及系统按钮行为。

## 验收（证据分层）

- 源码/几何：所有图标矩形均在工具栏内、互不重叠；800×550、1180×780、200% 对应窄逻辑宽度覆盖。默认列表关闭、默认浅棋盘。
- egui 合成：图标点击走原业务函数；缩放、适应、1:1、旋转、撤销、菜单关闭、编辑/列表切换；菜单打开不误触旋转/导航，Esc 只关闭顶层；原输入框焦点/导出/裁剪回归继续保留。
- 数据：背景切换前后 PNG alpha、像素及导出一致；源文件始终未改；四次旋转恢复像素，撤销工作正常。
- Windows 原生：800×550 和 100/150/200% DPI截图；真实鼠标/键盘、中文路径、Tab/Enter/tooltip、菜单外点、Esc；文件对话框与拖放；快速切图与面板反复开关。
- 安装：标准/自选每用户目录、升级/失败恢复、卸载归属保护；提示未选不打开设置，静默不弹设置；选中仅打开设置，关联须用户自己确认；Win10通用页、支持版本Win11定向页及失败回退。
- 云端没有完成的 Rust/Windows 项目明确标为未运行，不能以几何/静态脚本替代原生证据。

## 审查修正：稳定打开后的 More 再次点击

More 作为前景 modal 时，底层按钮可能不再接收 egui clicked 事件。菜单应显式接管已打开时 More 区域的点击关闭，且不得把同次释放再当成重新打开。验收先让菜单稳定绘制多帧，再重复打开→点击 More→关闭；原即时点击、F10、Esc、外点及 Enter 焦点隔离仍须通过。此项不改变菜单功能或视觉布局。
