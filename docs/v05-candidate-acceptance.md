## 已实现的范围

### P0

自然顺序、取消/过期结果隔离、固定有界任务槽、主图优先于缩略图；完整后台任务所有权和按阶段退出日志。所有正常 worker 不保留/调用 egui Context，因此在 UI 持锁的退出路径中 join 不会反向等待 Context。

未导出保护覆盖打开、拖入、导航、粘贴、恢复与关闭；导出成功才恢复已确认的单一原意图。取消/失败放弃继续意图，保留编辑。原图与当前图片指针分开，成功导出后用弱引用识别已导出像素，不额外保留大缓冲；撤销到该像素不重复误报未导出。

较大图切换释放旧全尺寸文档；纹理上传直接按行转换，不生成额外 RGBA tile 副本；同尺寸动画复用 texture ID。跨 UI 帧保留交接预算，但没有把它描述为真实 GPU fence 或驱动资源测量。

旧设置文件保持 schema 1。读取失败有说明，后续保存拒绝覆盖不兼容/损坏原文件。

### P1

GIF/WebP 静态与有界流式动画；显式剪贴板 PNG/DIBV5/DIB 与本地单文件；当前完整图像复制和独立命名的路径复制；长图、全屏显隐、7/8/11 图标溢出、窄窗编辑抽屉与逐层退出。

动画先确认提取静态帧才编辑/导出。动画失败必须从头重新开始，不假装能从丢失的 decoder 状态续播。>4MP 动画安全拒绝；单帧 GIF 走静态 16MP 限制。帧数/损坏中断保留最后帧。无编码全部动画、额外模型或服务器。

### 每轮证据身份

记录实际 dev 候选 commit、Debug/Release 主程序与 worker、Setup SHA-256、Windows/驱动/DPI、样本 hash、是否物理输入；所有报告绑定同一轮产物。若修改源码，重跑受影响测试及汇总。

### 长时测试的调度说明

现有 `--include-ignored` 会运行新增的 30 分钟核心 soak，因此 Debug/Release 各跑一次默认合计约 60 分钟，使用正式构建脚本或显式 `--nocapture` 时会按分钟输出；普通 cargo 捕获输出时可能到测试结束才显示。这不是进程卡死。构建报告记录每 profile 实际请求秒数和 short-smoke 标识，不把短测记为长时通过。

可先在完整原生 Debug/Release 门禁前显式设置 `GLOAMERE_ANIMATION_SOAK_SECONDS=3`，把该项标为 3 秒核心冒烟；其他来源/导出等 ignored 回归仍照常完整执行。随后清除这个环境变量，单独运行 Release 的 `cargo test --release --test animation realtime_animation_soak_30_minutes -- --ignored --nocapture --test-threads=1` 完成默认 30 分钟核心 soak。短冒烟不能替代长时。

核心 soak 与 GUI 播放是两项门槛：前者验证固定样本核心 decoder/时序/持有预算，后者必须在真实原生窗口验证纹理上传、GPU/CPU/进程私有内存、前后台行为和可见播放。云端核心长测完成也不能勾选原生 GUI 长时项。
