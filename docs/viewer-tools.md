# 查看工具与文件操作

本文说明当前开发候选的交互和资源边界，不代表 Windows 原生输入、DPI、剪贴板或多窗口验收已完成。查看选项只在当前会话生效，不写入 `settings.json`；明确确认文件重命名会修改磁盘上的原文件名称。

## 入口

| 功能 | 入口 |
| --- | --- |
| 显示/隐藏图片列表 | 标题栏左上角分栏按钮；列表标题旁也可隐藏；每次启动默认收起 |
| 排序、格式筛选 | 图片列表搜索框下方“筛选与排序”按钮，或“更多（…）→ 查看 → 素材排序与筛选” |
| 像素取色、显示采样、Alpha 查看 | “更多 → 查看 → 像素与透明度检查” |
| 固定 A 图、同步视图、交换左右、退出对比 | “更多 → 查看 → 双图 A/B 对比” |
| 独立贴图置顶 | 主窗口标题栏右侧小图钉，也可右键“贴图置顶”，或“更多 → 查看 → 贴图置顶（独立参考窗）” |
| 当前窗口置顶 | “更多 → 查看 → 当前窗口置顶” |
| 重命名当前文件 | 双击主窗口标题栏左侧的文件名 |
| 画布常用动作 | 主画布或 A/B 的 B 画布单击右键；空画布可打开、粘贴 |
| 重新载入、文件夹定位、复制路径 | “更多 → 文件” |
| 撤销、重做 | “更多 → 编辑”，或 Ctrl+Z、Ctrl+Y / Ctrl+Shift+Z |

AI 检测仍位于“更多 → AI 检测当前图片”，只在明确点击时执行；这些查看工具不会自动检测图片。

## 主窗口标题栏与重命名

标题栏左侧显示当前文件名，长文件名省略显示。双击文件名进入重命名；双击标题栏其余空白区域切换最大化/还原，拖动空白区域移动窗口。右侧的小图钉创建独立贴图，最小化、最大化/还原与关闭分别操作主窗口。标题栏按钮不占用画布显示区域。

重命名只接受当前文件的新主名，保留原扩展名和所在目录。确认后在后台修改磁盘上的原文件名称；同名文件已存在、名称无效或系统拒绝操作时显示原因，不覆盖现有文件。成功后当前文件名、路径及目录选择同步更新，已有贴图继续保留创建时的冻结内容。

有未导出修改时提示先导出副本或放弃修改，再重新发起重命名；不会直接改名，导出失败或取消时保留当前编辑。剪贴板图片和提取的临时帧没有原文件名称，不能重命名。加载或其他互斥操作期间不可开始重命名；执行期间不切换文档，正常关闭也要等操作结果落实。

编辑文件名时，复制、粘贴与输入法保持文本语义。取消名称输入不会修改文件；已经完成的磁盘重命名不会被晚到的取消伪装成失败。

## 画布右键菜单

主画布和 A/B 对比的 B 画布均可单击右键打开常用菜单：贴图置顶、复制图像或动画当前帧、导出静态副本、适应窗口和实际像素 1:1。编辑分组提供旋转、撤销、重做，文件分组提供打开、粘贴、F5 重载、文件夹定位和复制路径；AI 检测也只在明确点击后执行。编辑后的文件文档标明“AI 检测原文件”，不把原文件检测冒充当前编辑像素的结果。

空画布右键只提供打开与粘贴。加载、后台操作、确认窗口或无有效画布时，相应动作禁用；临时图片没有文件路径操作。动画可以复制或贴出当前帧，编辑、导出仍沿用明确提取静态帧的流程。

右键单击与右键拖动分别处理。按住右键拖动画布仍可平移，裁剪选择期间也保留右键拖动平移，不会因新增菜单而改成裁剪动作。

## 像素与透明度检查

默认关闭像素检查器。开启后，在当前图片内悬停显示从 0 开始的图片坐标、RGBA 和 `#RRGGBBAA`；单击图片把该 HEX 颜色写入系统剪贴板，成功或失败均显示结果。坐标跟随实际显示区域的缩放、平移和裁切，不采集图片外、棋盘背景或 A/B 的 A 图。

数值来自当前文档的 sRGB / 8 位像素，包括当前编辑结果；透明像素仍可显示其原有 RGB。它不是屏幕截图取色，也不代表读取输入文件原始位深。ICC 转换失败的既有颜色限制仍适用。

“平滑”和“锐利 / 像素”切换显示采样，后者适合放大检查像素边缘；不会修改源像素，也不会改变导出缩放算法。

开启“查看 Alpha 通道”后，透明度显示为不透明灰度图：黑色完全透明，白色完全不透明，中间灰度表示部分透明。取色仍读取原来的 RGBA；复制整张图片、编辑和导出也继续使用原像素。

Alpha 派生及 CPU 显示准备在后台执行，准备期间保留正常画面并显示状态。切图或编辑会使旧任务和旧 Alpha 失效；任务失败或预算不足时继续显示正常图，可在菜单中显式重试。动画（包括暂停帧）、A/B 对比、切图和其他处理中暂不显示 Alpha；保留已勾选的请求，回到可用的静态单图后重新准备。

## 素材排序与筛选

- 默认按文件名自然排序；也可选择修改时间新到旧/旧到新、文件大小大到小/小到大。
- 属性相同时按自然文件名排序；无法读取属性的条目排在最后。排序使用目录扫描得到的属性，不为排序完整解码每张图。
- 格式筛选提供全部、JPEG、PNG、GIF、WebP，按不区分大小写的文件扩展名匹配；实际打开图片仍以内容探测为准。
- 格式、文件名搜索和 AI 状态筛选取交集。改变排序或筛选不强行切走当前图；当前图即使不在结果中仍可保留在画布，后续导航使用筛选结果。
- 目录刷新会重新读取属性。目录扫描、图片数和缩略图仍受 README 所列上限约束，不支持递归素材库或索引数据库。

## 双图 A/B 对比

1. 打开静态图片，选择“固定当前图片为 A，开始对比”。A 保存该时刻的像素与显示状态，可来自文件、剪贴板或已编辑的静态图片。
2. 打开或切换另一张作为 B。B 始终是当前文档，编辑、撤销/重做、复制、导出和像素检查只针对 B。
3. “交换 A / B 左右位置”只交换画面位置，不交换文档身份或编辑目标。“将当前图片重新固定为 A”可更新参考图。
4. 选择“退出对比并释放 A 图”结束对比；成功打开动画也会退出对比。窗口过小时暂显示当前单图，扩大窗口后恢复双图。

默认勾选“同尺寸图片同步缩放 / 平移”，仅在两图尺寸相同且 B 未处于长图模式时生效；其余情况分别缩放和平移。不提供自动对齐、像素差异图或动画双图播放。对比期间暂停 Alpha 查看，退出后按原选项恢复。

A 图保留固定时刻的内容，后续编辑 B 不会覆盖 A。固定图共享已有像素/纹理的所有权，继续占用相应预算；打开 B 所需的新数据也必须通过预算准入。退出对比后，A 的显示资源在渲染交接结束后回收。

## 独立贴图置顶

点击主窗口标题栏右侧的小图钉，即可创建独立原生参考窗。图钉为正立、左右对称的图标，与主窗口控制按钮排列在外框中，不覆盖图片或序号；也可在画布右键选择“贴图置顶”，或通过“更多 → 查看 → 贴图置顶（独立参考窗）”创建。

贴图无边框、无工具栏，窗口只显示图片；操作收在右键菜单中。最多同时 3 张；达到上限时显示原因，先关闭一张再创建。显示后端不支持独立原生窗口时拒绝创建并提示原因。

贴图冻结创建时已经显示的图片，包括当前编辑结果；动画冻结当前已显示的合成帧，原动画可在主窗口继续播放。创建后，主窗口可以继续切图、编辑和导出，已有贴图保持原内容，不重新读取文件或自动检测图片。A/B 中从 B 画布创建贴图时，内容仍来自当前文档 B。

贴图使用正常图像画面与创建时的画布背景。图片和右键菜单之外完全透明，不显示底色，也不阻挡下方窗口的鼠标操作。Alpha 灰度查看、取色提示、裁剪框等查看覆盖层不进入贴图。

- 按住图片拖动可移动整个贴图窗口。
- 鼠标悬停在图片上即可用滚轮按宽高比连续缩放，无需先点击激活贴图。连续滚动会接续目标尺寸，始终完整显示图片；初始大小按图片比例限制在 640 × 480 逻辑点内，小图不额外补边。
- 贴图内的右键菜单提供“窗口置顶”“恢复初始大小”和“关闭这张贴图”；恢复初始大小也使用平滑过渡。关闭置顶后，贴图仍可作为普通独立窗口使用。
- 缩放动画结束后，不再为动画定时重绘；静置贴图不会持续刷新。
- 贴图窗口获得焦点时，Esc 只关闭该贴图；也可通过右键菜单“关闭这张贴图”关闭。
- 主窗口退出时关闭全部贴图，不创建托盘后台服务，也不在下次启动时恢复贴图。

贴图共享创建时已准备的显示像素与纹理所有权，主窗口随后更新会保留冻结内容。相关资源仍占应用预算，关闭后经渲染交接回收。

## 当前窗口置顶

“更多 → 查看 → 当前窗口置顶”作用于主查看窗口，可与单图或 A/B 对比一起使用。切换时保持当前大小和位置，之后仍可手动移动、缩放窗口；在同一菜单中取消勾选可恢复普通层级。默认关闭。要让参考图片独立保留并继续使用主窗口，应使用上面的贴图小图钉或“贴图置顶”入口。

## 重做、重新载入和文件操作

- Ctrl+Z 撤销；Ctrl+Y 或 Ctrl+Shift+Z 重做。新编辑会清空重做分支。撤销/重做合计最多 3 项、256 MiB，历史像素与已准备的 CPU 显示数据共同计入；资源不足时不先替换当前文档。
- F5 重新载入当前文件，并清除静态浏览缓存；有未导出修改时沿用确认流程。它不执行目录后台监视，也不是文件夹定位快捷键。
- “更多 → 文件 → 在文件夹中显示”在 Windows 文件资源管理器中定位当前文件；“复制文件路径”复制当前文件路径。两项均需文件文档，剪贴板图片、提取帧和载入期间不可用；文件夹定位在其他平台暂不支持。
- Ctrl+C 仍复制完整图片或当前动画帧，与复制文件路径、单击复制 HEX 分别使用独立入口；文本框有焦点时保留文本复制语义。
- 导出切换 PNG/JPEG 时保留自选目录和文件主名，仅修改扩展名，并使旧 JPEG 预览失效。导出仍创建新副本，不覆盖原图或同名文件。

## 资源边界

Alpha 的派生像素、CPU 显示数据、纹理上传交接、A/B 固定图，以及独立贴图共享的像素/纹理和原生显示缓冲均纳入应用全局预算；取消与切图会阻止旧结果重新显示。资源不足时保留可用画面并显示原因，不通过后台重试无限申请资源。

每张贴图从创建到关闭保持固定绘制画布，按所用显示器工作区的实际物理面积预留显示缓冲预算；16 MiB 仅为每窗下限，不代表每窗固定占用或最多占用 16 MiB。图片在透明画布内由 GPU 连续缩放，原生窗口不随每帧动画改变尺寸；原生区域限制可见及鼠标命中范围到图片和菜单。缩小图片不缩减固定画布的预留，关闭后再经渲染交接回收。

768 MiB 全局预算是应用准入估算，不能等同进程私有内存、显存或驱动内存的硬上限。默认输入上限、动画解码和缩略图限制仍见 [README](../README.md#资源与颜色边界)。本说明未增加格式支持、系统级截图取色或跨平台分发承诺。
