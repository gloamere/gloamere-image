# 中文字体回退验证设计（验证前）

现机正常窗口已使用 Microsoft YaHei 显示中文，但这不证明主字体不可读时的回退。保留现有系统字体查找顺序，将候选列表读取提取成同一配置函数；普通运行路径不变。仅显式 QA 模式允许把第一候选换成确定不存在的路径，第二候选仍读系统 SimHei。不能删改系统字体或安全配置，也不随包分发系统字体。

内部测试确认第一候选缺失、选择第二候选并完成中文 glyph 布局；实际 Windows D3D12 窗口查看回退后的中文标签、最小裁剪区和导出按钮。记录这是受控缺失主候选，不是不同 Windows 安装或输入法测试。全部 CJK 字体缺失的系统仍未验收，当前不承诺不具中文字体的干净系统可用。
