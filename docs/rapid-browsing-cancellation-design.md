# 快速翻图取消验证设计（测试前）

真实使用中，用户可能连按翻图键，上一张还在解码便已经选择下一张。串行打开 1000 次的窗口运行验证了长期使用，但没有直接覆盖请求重叠和取消传播。本次增加针对现有单工作线程、单待处理请求和 generation 过滤的回归，不新增产品入口。

使用实际 App 和 Windows 文件/解码工作线程，连续发送 1000 个交替图片请求，逐个保留上一请求的取消令牌，最终选择带独特尺寸和像素的图片。验收前 999 个令牌被取消、最终 generation/文件/像素相符、旧响应不能覆盖最后选择、原文件未变。随后选择无效文件，应得到可读错误，再选择正确文件可恢复；最后释放 App 并有界等待已拥有内存回到测试前水平。该测试检验内部加载行为，不能宣称真实键盘连按已经验收，也不代表库函数支持解码中途抢占。
