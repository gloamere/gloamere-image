# v0.5 浏览、worker 生命周期与偏好保护

实现范围：`src/browsing.rs`、`src/worker.rs`、`src/settings.rs`。本文只记录该部分的机制与验证，不代表 Windows 发布验收通过。

## 固定线程与协作退出

主图、目录、缩略图各持有一个固定 worker。主图是通用有界 worker 的适配器；每个 worker 最多有一个正在处理的请求、一个待处理请求和一个结果槽。新请求取消正在处理的旧请求、替换并取消旧待处理请求、清除旧结果。取消或退出后的旧结果不会重新发布；直接取消令牌后的已有结果也不会被消费。

worker 不捕获或使用 egui Context，不调用 repaint。应用在任一 worker 的 `is_busy()` 返回 true 时定期轮询；该方法也包含未读结果，避免检查时序使已完成结果失去下一次轮询。现有构造函数的 Context 参数只为兼容调用入口保留。

`shutdown(&mut self)`：

1. 禁止接收新请求，后续请求的取消令牌会被取消。
2. 取消活跃与待处理工作，清空结果槽并唤醒空闲 worker。
3. 释放所有 worker 互斥锁后 join 自己持有的线程。
4. 返回并缓存 `ShutdownReport`：耗时、是否取消活跃任务、是否丢弃待处理/结果、join 是否遇到 panic。重复 shutdown 返回同一份报告，Drop 也走同一路径。

每个 worker 记录 shutdown begin/complete 日志及名字；若退出卡住，begin 而没有 complete 可以帮助定位阶段，但不能代替线程栈。操作 panic 转成可恢复错误，后续请求仍可处理。

取消仍是协作式。同步 codec、操作系统文件系统等待、GPU 驱动等待不保证可随时中断，也没有假装已结束的超时 detach 或强制退出。在 egui Context 锁持有期间 join 的回归测试验证了这些 worker 没有 repaint 锁的依赖；不证明 GPU 或系统 I/O 退出延迟已有上界。

## 自然排序与格式列表

目录扫描与补回当前图使用同一套排序。文件名先转 Unicode 小写；ASCII 数字段按数值大小比较，不转为固定宽度整数，因此很长的数字不会溢出。完整名称自然比较相同时，较少前导零在前，最后按原始路径打破大小写或有损转换等平局。中文按 Unicode 编码顺序，不做拼音或系统区域排序。

固定样例包括 `image2.png < image02.png < image002.png < image10.png`、`图片2.gif < 图片10.webp`、`A.png < a.png`、多段数字与相同前缀。枚举顺序变化不会影响未截断集合的最终顺序。支持扩展名增加 GIF/WebP，大小写不敏感；真实内容仍由解码通路判断。原有 10000 条目、8000 图像及路径总量限制不变。

## 设置 v1 保留与拒绝写入

设置目录、`LIGHT_IMAGE_SETTINGS_DIR` 覆盖变量、schema v1 和三个既有字段保持不变，不新增迁移或偏好字段。合法 v1 文件继续原子写入，新文件使用同目录独占临时文件。

损坏、超限、未来版本、未知字段或未知背景值读入失败时暂用默认值并明确提示原文件保留。下次切换偏好前会重新验证现有文件；仍无法安全理解它时拒绝保存，不创建替代文件、不覆盖原始字节。该版本选择“拒绝保存”方案，不生成或覆盖恢复备份。用户需要先保留并人工修复/移开原文件，才能恢复持久化保存。多个进程同时编辑同一偏好文件不是本变更提供的事务或合并保证。

浅棋盘的两种颜色为 `#F1F3F2` / `#EBEFED`，不会改变图片像素或导出底色。

## 自动化与人工验收边界

聚焦测试覆盖：

- 数字、中文、大小写、前导零、超长数字及排序比较器反对称/传递关系。
- 500 次替换请求、活跃/待处理取消、旧结果槽清除、外部取消后的结果隔离。
- 活跃退出、空闲退出、待处理与已完成结果清理、重复退出、退出后请求拒绝、Drop 回收、panic 后继续工作。
- 持有 egui Context 写锁时的 worker join。
- 主图坏文件后恢复、路径与 generation 保留。
- 原 v1 字段保留，以及各种不支持配置在下一次偏好切换后字节不变。
- 准确浅棋盘颜色和原有目录/缩略图限制回归。

运行命令由主工程/云端 headless harness 提供。仍需 Windows 原生退出、慢/失效文件系统、GPU 释放、真实快速导航输入、安装升级与 DPI 验收；测试成功不能改写历史 60 秒退出超时为已解决。
