# v0.4 Windows QA 清单

本文件是后续 Windows 验收清单，不代表全部场景已测。当前已交付范围和未验证项见 releases/v0.4.0.md；安装迁移设计见 branding-installer-migration.md。请从明确的 Git 提交构建，并保留真实结果。

## 1. 构建门禁

- 记录 Windows、GPU、Rust、MSVC/SDK 和 Inno 版本。
- 执行 `scripts/verify.ps1`：fmt、严格 clippy、工作区/示例构建、包括 ignored 的全部测试（单线程）。先生成真实 worker 和故障示例，再执行依赖它们的测试。
- 使用 `scripts/build-release.ps1` 构建与校验配对主程序/worker；均为 0.4.0。
- 安装载荷 manifest/package 版本应为 0.4.0；`scripts/build-installer.py` 已接受该版本。用官方 Inno 6.7.3 编译。
- 保留完整通过/失败/忽略计数和来源版本；若需要修改代码，先把问题与最小复现交回云端，不直接扩写功能。

## 2. 原生渲染（与输入验收分开记录）

生成测试图只在明确的 QA 临时目录；生成前验证绝对路径落在该目录内且不是系统/用户图片目录。不扫描系统找图片，不复用危险旧脚本试验。

- 使用自制 JPEG、透明 PNG、损坏图以及中文/空格/&/括号文件名。
- 查看默认 1180×780、最小 800×550；100/150/200% OS DPI。默认棋盘填满画布，列表关闭，索引不遮按钮，底部所有 11 图标完整且单行。
- 旧偏好为深背景或列表开启时保留；新临时设置目录应默认浅棋盘/列表关闭。不要覆盖用户实际偏好来制造截图。
- More 各功能及四种背景可达；编辑/信息滚动条可见；裁剪选择时“应用裁剪”保持固定可见。
- 可使用自带 smoke 入口做程序内渲染验收，不能把它写成物理点击已测：`scripts/run-smoke.ps1` 支持 `-SmallWindow`、`-Scale`、`-ShowMore`、`-ShowList`、`-ShowEdit`、`-CropPreview`。默认 smoke 与新用户一致，列表关闭。
- 记录 `runtime.json` 的 viewer_ui 按钮矩形、canvas、GPU 和截图。

## 3. 实际输入（有受支持 Computer Use 才执行）

- 鼠标打开/前后/缩放/适应/1:1/右转/撤销/导出；重复快速切图，忙时取消。
- More 反复开/关，点外部、Esc、F10；Tab/Shift+Tab 留在菜单，Enter 只触发聚焦项；关闭后恢复 More 焦点。
- 焦点在工具栏时 R/Shift+R/F/1/F10 可用；路径、导出名称或数值输入中不误触切图/旋转。
- 编辑与信息面板可关闭；原有裁剪、缩放、翻转、撤销、恢复原图保留。
- 导出完成提示可见、原图不改、重名拒绝；背景切换不改变透明度或 JPEG 导出底色。
- 系统文件对话框取消、中文输入、真实拖放和屏幕阅读器检查另记。
- 没有受支持输入工具时明确“未测”；不得用 UIA、SendKeys 等绕过工具限制。

## 4. 安装和系统默认应用

完整安全设计见 default-apps-v0.4.md。只在原有允许的隔离 QA 范围内测试产品自有键和目录；先快照，不改 UserChoice。

- 安装完成选项默认未勾选。不选不打开系统设置；静默安装不打开；取消安装不打开。
- 用户选中后仅打开 Windows 设置；Win10/老 Win11 通用页，Win11 22631+ 客户端定向页。不支持/被策略禁用时记录实际行为，不绕过系统策略。
- 系统能够发现 Light Image Tool 的 `.jpg/.jpeg/.png` 候选，正确引用安装 EXE 和带引号的 `%1`。不添加其他格式。
- 安装前后 UserChoice/现有双击默认保持不变。是否选择轻图为默认必须由用户本人在 Windows 中确认，不替用户点击该最终选择。
- “图片右键菜单”仍独立可选；当前用户范围，无管理员提示。
- 重跑 v0.3 安装生命周期/恢复专项（原已验证 10+7 项只是历史基线）：默认/自定义中文目录、升级、占用拒绝、取消、受控失败、恢复数据保留与卸载。
- r2 类型保护：将候选值、OwnerId/OwnerPath、ProgID 命令改为同文本 REG_EXPAND_SZ；预检拒绝，失败恢复保留并报告，卸载不删。测试类型查询失败/视图选择，保留旧快照。
- r2 共享父键：在独立注册表夹具中让 RegisteredApplications 仅含产品发现值，恢复移除该值后空的共享父键仍应存在，只有产品专用空子键可清理。
- 新增 14 个默认应用候选注册值：新装/重复安装；外来/变更值拒绝；部分写入失败只恢复本安装已写且仍匹配的值；卸载只删匹配归属值，不动外来值。
- 候选注册在 ssInstall 致命边界、已验证恢复快照之后、复制 EXE 之前。新装期间有短暂候选尚无 EXE 的窗口；失败必须回滚；完成页仅成功后提供设置入口。
- 如果用户之前已手动选轻图为默认，卸载不写 UserChoice；检查 Windows 对已不存在 handler 的表现，准确记录，不能承诺替用户恢复旧默认软件。
