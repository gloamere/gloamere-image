# 使用流程补充设计 v0.2 / 2026-10-07 18:20 UTC

本设计补入委托方提供的场景要求，不代表原 DOCX 或示意图已读取。

## 图片中心交互

右侧信息/来源面板默认收起；编辑时展开编辑面板。顶部只保留打开、翻图、
适应/100%、编辑、导出、信息。底部显示文件名、像素尺寸、格式、倍率和状态。
快捷键：左右同目录翻图，F 适应，1 实际像素，Ctrl+O 打开，Ctrl+Shift+S 导出，
Ctrl+Z 撤销；输入框焦点时不抢翻图/编辑快捷键。Esc 先退出编辑，再退出全屏。
PNG 转 JPEG 时先选底色，并在真实画布预览合成结果；JPEG 无透明选项。
加载世代控制结果归属，待加载请求最多一个，不预取全分辨率图片；空闲不重绘。
大图采用 egui 普通纹理分片（每片 2048），原因是 eframe 默认 GPU 纹理边长 8192，
而允许输入边长 32768；不能悄悄降采样后声称 100% 实际像素。

## 导出事务

同目录独占临时文件 -> 编码 sRGB 像素及一致的 sRGB ICC -> sync -> 回读并验证
格式/尺寸/无继承方向与 C2PA -> 检查取消 -> 原子防覆盖发布。原路径、已存在目标、
名称竞争、权限不足、空间不足、取消不覆写原件。仅删除当前事务临时文件。
色彩未能正确处理的输入可查看并显示警告，但首版拒绝宣称正确色彩的导出。
16 位输入明确说明 8 位显示/导出限制。输出不复制 EXIF、XMP prompt、GPS 或凭证。

## 来源状态与缓存

普通 EXIF 和未签名 AI 声明分别显示，与 C2PA 签名/资产绑定/信任结果独立。
无凭证、核验错误、不支持、超时、离线资料不足各有状态；不把它们归为真实照片。
来源 worker 使用官方 SDK，default features 关闭、Rust native crypto、HTTP feature
关闭，remote manifest、OCSP、证书信任资料联网关闭，并做本地监听测试。
由文件完整 SHA-256 + 策略版本 + 信任快照版本标识结果，核验时间独立记录。
缓存只保存小型报告、按字节限制；未建立可信快照时“未配置信任资料”明确可见。
图片读取与来源读取最好基于同一不可变输入快照，若文件改变则不能显示旧有效状态。
编辑副本展示原文件证据仅用于参考，当前像素不继承可信徽标。

## 验证证据与限制

仓库分别记录 Windows 编译、D3D12 实际运行、内部输入模拟、导出安全与来源检查。当前环境未提供可用的前台自动化入口，真实键鼠和中文 IME 尚未验收；Windows 11、Mac、实际 OS 缩放切换和 GPU 设备丢失未测试。应用自身渲染 QA 可以检查布局与字形，不能替代系统交互结论。磁盘满采用 writer 返回 Windows 错误 112 的受控注入验证，不填满系统盘。
