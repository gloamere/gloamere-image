# 常用素材工作流的可读性与来源状态设计

依据本机正常图、来源面板与16MP窗口检查，保持画布主位。开发者看尺寸与编辑状态、内容制作者看来源解释时，底部状态及说明至少14逻辑点并提高与深色背景的对比；不以弱灰、小字传达取消/失败或来源边界。

工具栏按打开、浏览缩放、编辑导出分组，在窄窗允许整组换行；路径输入保留为次级链接。编辑入口使用与主要操作一致的按钮，旁边提示“裁剪 · 旋转 · 缩放”，选中样式表达面板已开。图像原件、导出副本及来源安全行为不变。

来源状态分两层：任务阶段为未开始、核验中、完成、取消、失败；完成的证据仍使用worker的无凭证/签名/不完整/错误。无凭证显示“未发现嵌入凭证”，签名/绑定为“不适用”，不能写未完成暗示任务仍运行。Signed的签名/绑定结果与信任快照逐项显示；NotChecked显示“未核验”，远端资料不能读取时明确“离线资料不足（核验不完整）”；取消和IPC失败不可降格成无凭证，不缓存为正常结果。

## 导出对话框布局修订

实际 JPEG 预览渲染显示首次导出窗口靠左上覆盖工具栏，完整路径控件过窄。将打开路径、导出和错误提示作为居中对话框，禁止折叠并保留关闭/取消行为；导出宽度按 480 逻辑点起步，路径随可用宽度展开，质量和透明底色预览仍清楚区分。对话框尺寸不能溢出 800×550 最小窗口；需采用滚动容器并在渲染 QA 中检查最小窗口。提高常规文字和按钮前景颜色，禁用状态由框架透明度处理。该改动不改导出写入规则或文件命名。

最小窗口 JPEG 预览渲染显示整个对话框滚动会把“导出副本”按钮放到折叠区域。调整为顶部原图保护说明和底部主按钮固定可见，仅中间格式、路径、预览与说明滚动；预览不应挤掉保存操作。
