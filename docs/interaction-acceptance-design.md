# 交互与可访问性验收设计

使用场景：浏览素材时方向键翻图；输入路径时按键编辑文字；编辑和导出对话框打开时 Esc 先关闭最上层提示或对话框，再退出编辑/全屏。任何操作不能修改原图；切图或编辑会撤销陈旧导出意图。

内部 egui RawInput 回归使用真实 App::ui 和控件，检查焦点隔离、快捷键、Esc 层级和异步编辑/导出状态。测试可以验证应用的事件处理，不代表实际 Windows 键鼠或输入法验收。当前环境未提供可用的前台自动化入口，真实键鼠和中文 IME 尚未验收；OS 缩放切换、辅助技术实际互操作和 GPU 设备丢失也列为未验证。

路径控件具有固定 egui Id。可访问性 SetValue 仅接受对应节点和 ROOT tree 的事件，只在已显示的打开/导出路径控件中同步 String，限制为 32767 个 UTF-16 单元；拒绝其他节点、过长输入和关闭对话框的陈旧事件。该操作不会自动打开或导出。普通 TextEdit 继续处理文字、选择和输入法事件。

验收：内部测试正确节点、错误节点、长度边界和关闭对话框；实际 Windows 构建；应用自身渲染检查中文字形、高 DPI 下控件布局、编辑与导出状态。渲染结果与原生交互结果分别记录，应用截图仅保留本地，不进入交付附件。
