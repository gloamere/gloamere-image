# gloamere-image 0.4.0

Windows x64 未签名测试版。JPEG/PNG 本地查看、尺寸和透明度检查、按需离线来源检查、裁剪/旋转/翻转/缩放、撤销及新副本导出已形成可运行闭环。Rust + egui/eframe + wgpu 共用 UI 和图像处理；本次实际 Windows 图形后端为 D3D12。Mac Metal 尚未构建或运行。

安装与手动更新使用 `gloamere-image-0.4.0-Win64-Setup-unsigned.exe`，按用户安装。沿用旧版本安装身份、目录和偏好，保留一个产品入口；候选关联不改写 Windows UserChoice。当前没有自动更新、图片上传、遥测或自动联网来源查找。来源结论区分证据、签名和信任边界，不能判定图片内容的普遍真伪。

## r4 修复

导出任务保留文件所有者的线程句柄。正常退出或渲染故障退出时先取消，再等待文件所有者完成临时文件清理；不扫描目录或删除同前缀外来文件。JPEG 编码按行检查取消。已发布副本保留，取消与发布采用互斥的状态转换。操作系统 I/O 可能延长等待，不承诺硬退出时限或强制终止后的清理。

## 已有实际 Windows 验证

以下结果来自已验收 r4 候选；本仓库保留其实现文件的相同字节。整理公开文档后的 Git 提交不是原安装器的构建提交，安装器当时如实标记为 `unversioned-working-tree`。

- Windows 10 build 19045 x64、RTX 4060；Rust 1.99.0、MSVC 14.44、Python 3.14、官方 Inno Setup 6.7.3。
- 正式发布流水线的 fmt、严格 Clippy、配对构建、PE 资源、许可收集、载荷校验和真实安装器编译通过。Debug 和 Release 各 113 项原生测试通过、0 失败、0 忽略；Python 85 项中 82 通过、3 因平台/权限跳过。
- 两个 profile 各 12 条实际 D3D12 诊断记录通过，覆盖查看、编辑、PNG/JPEG 新副本导出、连续翻图与取消、逻辑缩放和字体回退。每个 profile 两次 JPEG 在途 GPU 故障退出均无任务自有临时残留，保留原图、已导出 PNG 和同前缀外来文件。
- 新配对载荷的独立安装身份夹具完成 16 项实际安装、拒绝、迁移、后段失败恢复和卸载验证。生产身份安装器仅验证变更目录时安全拒绝；没有对用户真实安装执行升级或卸载。
- 主 EXE、worker 与 Setup 的九尺寸品牌图标资源、版本字段和未签名状态已核对。资源核对不代表 Explorer 或任务栏视觉验收。

第一次 Debug 故障 worker 测试超过原 5 秒断言；独立重测和正式全套重跑通过。并发编译时另一次 Debug 普通关闭在 60 秒限时内未退出，被诊断脚本终止；独立完整矩阵重跑及两 profile 单独进程观察正常退出。两项首次失败都保留记录，原因尚未确定，未放宽断言或限时。

## 已知限制与后续验收

真实键鼠、中文输入法、系统文件对话框、辅助功能、多显示器 OS DPI、Explorer/任务栏视觉、生产身份真实升级/取消/卸载、Windows 11 和其他 GPU/干净系统仍待验收。逻辑缩放和诊断驱动输入不代替这些测试。

当前实际在途 GPU 组合只验证 JPEG；PNG 在途 GPU、物理取消或导出中物理关窗未执行。正常退出等待仍需调查上述偶发迟滞。需要独立网络抓包补充现有关闭 SDK HTTP、拒绝 resolver、离线 worker/loopback 不连接测试。性能和内存预算未完成完整测量。

JPEG/PNG 是首版范围；BMP、其他格式、批处理和实验水印未实现。编辑副本不继承原图有效 C2PA 徽标。没有签名证书；这不是生产成熟或完整跨平台交付声明。
